# TradingProject.Persistence.Api.Stubs

Stub library for the V1 API of `TradingProject.Persistence`. 

Provides contracts (interfaces) and in-memory stub implementations for other services to reference directly without depending on the full API project.

## Contents

- **Models/** — Request/response DTOs matching the V1 API surface
- **V1/** — API contract interfaces (`ITradesApi`, `IOpportunitiesApi`, `IPortfolioSnapshotsApi`)
- **Stubs/** — In-memory stub implementations for testing and development
